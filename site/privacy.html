Privacy notes

Porchlight has no account, no analytics, no advertising and no cloud. What it learns about your network stays in one file on your computer. Here is every connection the Windows app makes, so you can check for yourself.

Connections inside your network

To do its job, Porchlight talks to the devices on the network you told it is yours:

  • "Who has this address?" (ARP) to every address on your home network, to find the devices that are on.
  • Asking devices their name the way your computer already does (mDNS, NetBIOS, UPnP, and the names they advertise for their services), asking your router which name each device gave it when it joined, and opening each device's own front page to read its title.
  • Knocking on common doors: a connection to a short list of ports that is closed straight away, plus a harmless hello to camera streams, Windows file sharing and Remote Desktop to see how they answer. It never logs in, never tries a password, never changes a setting.
  • Listing the ports your router opened for devices (UPnP), read-only.
  • Listening to Wi-Fi beacons your access points broadcast to everyone anyway, and this computer's own connection events. Nothing is sent over the air.

Connections that leave your network

  • One update check a day to porchlight-beryl.vercel.app, which hosts this site (on Vercel). It asks for a small file that says which version is newest. Like any website visit, the host sees your IP address; nothing else is sent. When you choose to install an update, the installer comes from the same address and is only used if its signature matches the key built into Porchlight.
  • One DNS test lookup per full checkup, for a made-up name under example.com (a name reserved for testing), sent to your usual DNS server. It shows whether your DNS invents answers for websites that don't exist. The name is random and says nothing about you.

That's all. There is no telemetry, no crash reporting and no "phone home".

What stays on your computer

  • porchlight-state.json: the devices it has seen, names you gave them, alerts and settings.
  • porchlight.log: what each check did and how long it took, capped at about half a megabyte.

Both are in %APPDATA%\com.aboutbeyrem.porchlight. Settings → Forget everything deletes the first and stops Porchlight from starting with Windows; uninstalling removes the app.

If you report a problem

Settings → Save diagnostic file writes a text file to your Downloads folder. It has counts (for example "3 × phone or tablet"), check IDs, timings and the recent log with every address removed. It never contains device names, Wi-Fi names or addresses. Nothing is sent automatically: you decide whether to attach it to a report on GitHub.

The website

This site has no cookies, no analytics and no third-party scripts. The demo at /demo shows a made-up home and never scans anything.
